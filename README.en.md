## View the exercises

Clone or download the repository, then open an exercise's HTML file in a modern browser. Keep the `images` folder in place so the gallery images load. No package installation is required.

A starting point is [Ejercicio9.html](Gonzalez%20Mateo%20Cristian%2002-03%20etiquetas%20HTML%20listas%20%2C%20definiciones%20y%20dialogos/Ejercicio9.html), the interactive gallery.
