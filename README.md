## Ver los ejercicios

Clona o descarga el repositorio y abre el archivo HTML de un ejercicio en un navegador moderno. Mantén la carpeta `images` en su ubicación para que se carguen las imágenes de la galería. No necesitas instalar paquetes.

Puedes empezar por [Ejercicio9.html](Gonzalez%20Mateo%20Cristian%2002-03%20etiquetas%20HTML%20listas%20%2C%20definiciones%20y%20dialogos/Ejercicio9.html), la galería interactiva.
