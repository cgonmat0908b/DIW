6. Escribe en un documento htm con el titulo <h1> Atributos button </h1> una lista de ordenada que explique cada atributo.

Atributos button

  • Formaction: Nos permite tener más de un botón de envio, puedo elegir un destino diferente para cada botón
  • formethod: Nos permite elegir entre GET o POST para el botón concreto
  • formenctype: Nos permite elegir la forma de codificación de los datos al enviarse
  • formnovalidate: No se validarán los datos al enviar mediante el boton
  • formtarget: Nos permite elegir con el botón concreto si se cargará en la misma ventana u otra nueva
