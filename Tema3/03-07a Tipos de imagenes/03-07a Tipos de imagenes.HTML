Tipos de Formatos

  1. ¿Qué es la codificación Bitmap?

    2. Es una forma de codificación formada por una rejilla de píxeles, cada uno con un color específico. Se usa en fotografías y gráficos con muchos detalles. Ejemplos: JPEG, PNG, GIF, BMP y WebP.

  2. ¿Sabes otro nombre para esta técnica? ¿Qué problemas tiene? Nombra algún formato de este tipo.

    3. Otro nombre es Raster o mapa de bits. Sus desventajas son que al ampliarse pierden calidad (se pixelan) y que el tamaño del archivo depende de la resolución y profundidad de color. Ejemplos: JPEG, PNG, GIF, BMP y WebP.

  3. ¿Qué es la codificación Vectorial? ¿Qué problemas tiene? Nombra algún formato de este tipo.

    4. Es un tipo de codificación que no usa píxeles, sino fórmulas matemáticas que definen líneas, curvas y polígonos. Se puede ampliar sin perder calidad y es ideal para logotipos, iconos e ilustraciones. Su desventaja es que no es adecuada para fotografías o imágenes con muchos detalles. Formatos: SVG, AI, EPS y PDF.

  4. Inserta esta etiqueta en un documento HTML y observa qué pasa:

    5. Aparece una estrella amarilla con el borde rojo. Es una imagen vectorial SVG creada directamente con código HTML, que puede ampliarse sin perder calidad.

  5. ¿Qué es un Meta formato? ¿Soluciona los problemas de los anteriores formatos? Nombra algún formato de este tipo.

    6. Es un formato que puede combinar imágenes de mapa de bits y elementos vectoriales en un mismo archivo. Permite aprovechar las ventajas de ambos tipos, aunque no elimina todos sus problemas. Sus desventajas son una mayor complejidad y tamaño. Ejemplos: PSD, AI y PDF.

Parámetros de Representación de Imágenes

  1. ¿Qué es la profundidad de color?

    2. Es la cantidad de bits que se utilizan para representar el color de cada píxel. Determina cuántos colores diferentes puede mostrar una imagen.

  2. ¿Cuál se suele usar actualmente?

    3. Se suelen utilizar 24 bits de color (8 bits por cada canal RGB), que permiten representar aproximadamente 16,7 millones de colores. También se utilizan 32 bits cuando se incluye un canal alfa para la transparencia.

  3. ¿Qué es el canal alfa?

    4. Es un canal que almacena información sobre la transparencia de los píxeles de una imagen. Permite que algunas partes sean transparentes o semitransparentes.

  4. ¿Qué es la paleta de color?

    5. Es el conjunto limitado de colores que puede utilizar una imagen o dispositivo. Por ejemplo, un GIF utiliza una paleta de hasta 256 colores por fotograma.

Formatos Gráficos

  1. ¿Qué es la paleta de color?

    2. Es el conjunto de colores disponibles para representar una imagen. Por ejemplo, GIF puede usar hasta 256 colores por fotograma, mientras que una imagen RGB puede representar millones de colores.

  2. Para cada formato, especifica sus características: compresión, tipo, uso en la web, programas, etc. Busca ejemplos utilizando filetype: en Google.

JPEG / JPG

Es un formato Raster con compresión con pérdida. Se utiliza principalmente para fotografías. Es compatible con prácticamente todos los navegadores y programas de edición de imágenes. No admite transparencias ni animaciones.

Buscar ejemplo JPG

PNG

Es un formato Raster con compresión sin pérdida. Admite transparencias mediante canal alfa. Se utiliza para logotipos, iconos y gráficos web. Es compatible con los navegadores y programas como Photoshop y GIMP.

Buscar ejemplo PNG

GIF

Es un formato Raster con compresión sin pérdida respecto a su paleta de colores. Permite animaciones y utiliza hasta 256 colores por fotograma. Es compatible con navegadores web. Se utiliza para memes y animaciones sencillas.

Buscar ejemplo GIF

SVG

Es un formato vectorial basado en XML. No pierde calidad al ampliarse y permite animaciones mediante CSS y JavaScript. Es adecuado para logotipos, iconos y diagramas. Se utiliza en páginas web y programas como Inkscape o Illustrator.

Buscar ejemplo SVG

WebP

Es un formato Raster desarrollado por Google. Permite compresión con y sin pérdida, transparencias y animaciones. Generalmente ocupa menos espacio que JPEG y PNG. Es compatible con los navegadores modernos.

Buscar ejemplo WebP

AVIF

Es un formato Raster basado en el códec AV1. Permite compresión con y sin pérdida, transparencias, animaciones y HDR. Ofrece una excelente relación entre calidad y tamaño. Se utiliza en la web moderna.

Buscar ejemplo AVIF

JPEG XL

Es un formato Raster moderno con extensión .jxl. Permite compresión con y sin pérdida, transparencias, animaciones y HDR. Puede recomprimir imágenes JPEG sin pérdida adicional de información. Su compatibilidad con navegadores es limitada.

Buscar ejemplo JPEG XL

HEIF / HEIC

Es un formato Raster con alta compresión, buena calidad y profundidad de color. Se utiliza principalmente en fotografías de teléfonos móviles, especialmente iPhone. Su compatibilidad web no es tan amplia como JPEG.

Buscar ejemplo HEIC

APNG

Es una variante animada de PNG. Utiliza compresión sin pérdida y admite transparencias y animaciones de buena calidad. Es compatible con los navegadores actuales. Utiliza la extensión .png.

Buscar ejemplo APNG

TIFF

Es un formato Raster de alta calidad. Permite compresión sin pérdida y diferentes profundidades de color. Se utiliza en fotografía profesional y escaneado. Es compatible con programas como Photoshop y GIMP, pero no se recomienda para páginas web.

Buscar ejemplo TIFF

BMP

Es un formato Raster de mapa de bits. Normalmente no utiliza compresión eficiente, por lo que sus archivos suelen ocupar mucho espacio. Se utiliza en entornos Windows y aplicaciones antiguas. No es recomendable para la web.

Buscar ejemplo BMP

PSD

Es un formato de Adobe Photoshop. Permite almacenar imágenes con capas, máscaras, efectos y transparencias. Se utiliza para edición profesional. Puede combinar elementos Raster y vectoriales. No se utiliza directamente como imagen web.

Buscar ejemplo PSD

QOI

Es un formato de imagen con compresión sin pérdida. Destaca por ser rápido y sencillo de codificar y decodificar. Admite imágenes RGB y RGBA. Se utiliza en aplicaciones gráficas y videojuegos. No es un formato habitual en páginas web.

Buscar ejemplo QOI

AI

Es el formato nativo de Adobe Illustrator. Se utiliza principalmente para gráficos vectoriales, ilustraciones y logotipos. Permite modificar y ampliar los elementos sin perder calidad. No es adecuado para utilizarlo directamente como imagen en una página web.

Buscar ejemplo AI

EPS

Es un formato utilizado para gráficos vectoriales e impresión profesional. Permite trabajar con ilustraciones escalables. Puede abrirse con programas como Illustrator. No se utiliza directamente en páginas web.

Buscar ejemplo EPS

PDF

Es un formato de documento que puede combinar textos, imágenes Raster y gráficos vectoriales. Mantiene la apariencia del documento. Puede abrirse en navegadores y programas como Adobe Acrobat, aunque no se utiliza directamente como imagen en HTML.

Buscar ejemplo PDF

Cuestionario: Formatos de Imagen Modernos

  1. ¿Qué formato de imagen utiliza habitualmente compresión con pérdida para fotografías?

    2. JPEG o JPG, ya que utiliza compresión con pérdida y es muy adecuado para fotografías.

  2. ¿Qué formato de imagen admite transparencias y compresión sin pérdida?

    3. PNG, porque permite transparencias mediante canal alfa y utiliza compresión sin pérdida.

  3. ¿Qué formato utiliza una paleta máxima de 256 colores por fotograma?

    4. GIF, que utiliza una paleta de hasta 256 colores por fotograma.

  4. ¿Qué formato de imagen fue desarrollado por Google?

    5. WebP, desarrollado para conseguir imágenes de menor tamaño manteniendo buena calidad.

  5. ¿En qué códec de vídeo está basado el formato AVIF?

    6. Está basado en el códec de vídeo AV1.

  6. ¿Qué formato utiliza gráficos vectoriales y permite ampliar las imágenes sin perder calidad?

    7. SVG, porque utiliza gráficos vectoriales definidos mediante XML.

  7. ¿Cuál es la extensión de archivo del formato JPEG XL?

    8. Su extensión es .jxl.

  8. ¿Qué formato es habitual en las fotografías realizadas con los teléfonos iPhone?

    9. HEIF / HEIC, porque ofrece alta compresión y buena calidad de imagen.

  9. ¿Qué formato permite crear animaciones utilizando imágenes PNG?

    10. APNG, que es una variante animada del formato PNG.

  10. ¿Qué formato se utiliza frecuentemente en fotografía profesional y escaneado de imágenes?

    11. TIFF, porque permite almacenar imágenes de alta calidad y utilizar compresión sin pérdida.

  11. ¿Qué es el formato BMP y cuál es su principal inconveniente?

    12. BMP es un formato de imagen de mapa de bits. Su principal inconveniente es que normalmente no utiliza compresión eficiente, por lo que sus archivos ocupan mucho espacio.

  12. ¿Qué es OxiPNG y para qué se utiliza?

    13. OxiPNG es una herramienta que optimiza imágenes PNG utilizando compresión sin pérdida. Sirve para reducir el tamaño de los archivos sin modificar su información visual. Está desarrollada en Rust.

  13. ¿Qué es MozJPEG y qué ventajas ofrece respecto a un codificador JPEG convencional?

    14. MozJPEG es un codificador JPEG optimizado. Permite reducir el tamaño de las imágenes manteniendo una calidad visual elevada. Mejora la compresión respecto a codificadores JPEG convencionales y mantiene su compatibilidad.

  14. ¿Qué es QOI y qué características destacan en su funcionamiento?

    15. QOI (Quite OK Image) es un formato de imagen con compresión sin pérdida. Destaca por ser rápido y sencillo de codificar y decodificar. Admite imágenes RGB y RGBA y no necesita algoritmos de compresión complejos.

  15. ¿Qué formato es especialmente adecuado para logotipos que deben ampliarse sin perder calidad?

    16. SVG, porque es un formato vectorial y puede ampliarse sin perder calidad.

  16. ¿Qué formatos de imagen permiten almacenar animaciones?

    17. GIF, WebP, AVIF, APNG y JPEG XL. SVG también permite crear animaciones utilizando CSS y JavaScript.

  17. ¿Qué significa HDR y qué formato de imagen de los estudiados permite utilizarlo?

    18. HDR significa High Dynamic Range (Alto Rango Dinámico). Permite representar un rango mayor de luces, sombras y colores. Los formatos AVIF y JPEG XL admiten HDR.

  18. ¿Qué ventajas presenta PNG frente a JPEG?

    19. PNG utiliza compresión sin pérdida, por lo que no pierde calidad al guardar la imagen. También admite transparencias mediante canal alfa, mientras que JPEG no las admite. Es más adecuado para logotipos, iconos y gráficos.

  19. ¿Cuál es la diferencia entre una imagen vectorial y una imagen rasterizada?

    20. Una imagen vectorial utiliza fórmulas matemáticas para definir líneas, curvas y polígonos, por lo que puede ampliarse sin perder calidad. Una imagen rasterizada está formada por píxeles y al ampliarse demasiado pierde calidad y se pixela.

  20. ¿Qué sucede al recomprimir una imagen JPEG mediante JPEG XL en modo sin pérdida?

    21. Se puede reducir el tamaño del archivo JPEG sin perder información adicional. La imagen mantiene exactamente su calidad original y puede recuperar el JPEG original cuando se utiliza la recompresión reversible.
